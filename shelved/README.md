# Shelved work

Everything in this folder is kept as a record and is not part of the live project. The live project is being started again from
scratch, following `docs/project_specification.md`.

| Folder | Content |
|---|---|
| `pilot_v1/` | The complete first version of the project: the training code, the language-model pilot, the pilot report, the pilot results and weights, the tests and a single entry script. It also contains the shelved recall task (MQAR) in `pilot_v1/mqar/`. |

`pilot_v1/` is a self-contained snapshot. It runs from inside its own folder, and nothing outside it is imported. Start with
`pilot_v1/README.md`.
