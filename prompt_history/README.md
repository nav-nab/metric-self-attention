# Prompt history

This folder records the prompts that directed the project. Several Claude agents worked on it in turn, each in its own session, so each has its own file.

Every file lists the user's prompts in order, word for word where the transcript survives, with a short note on how the agent responded. Entries that had to be reconstructed are marked as such.

## Files

| File | Agent | Content |
|---|---|---|
| [`analysing_and_writing_agent.md`](analysing_and_writing_agent.md) | Analysed the results, ran the statistical tests, wrote and revised the paper, tidied the repository | 40 prompts: 15 reconstructed, 25 verbatim |
| *more to come* | The other agents | Pending |

[`AGENT_PROMPT.md`](AGENT_PROMPT.md) is the prompt that asks an agent to write its file. It records the format and the rules.

Once every agent has added its file, they will be merged into a single navigable history.
